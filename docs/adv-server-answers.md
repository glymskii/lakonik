# Ответы на вопросы ADV по серверу и переносу (письмо Алины от 22.09.2026)

Черновик для ответа в ветке «Проекты с Галмыжаном». Технические детали — для Азамата, разворачивать по
`deploy/README.md`; комплект (`docker-compose.yml`, `Caddyfile`, `.env.example`, инструкция) передаётся вместе с письмом.

## По серверу и инфраструктуре

**1. Стек.** Linux + Docker. Сервер — Node.js 22 (TypeScript, Hono), очередь задач — pg-boss поверх Postgres,
обработка аудио — ffmpeg. Мобильное приложение — нативный iOS (Swift/SwiftUI), ставится из TestFlight/App Store.

**2. Упаковка.** Да, всё в Docker: один образ на API и обработчик + `docker-compose.yml` (Postgres, хранилище
MinIO, Caddy с автоматическим TLS). Образ приватный в GitHub Container Registry, доступ по токену для вашего
администратора — код закрыт, сервер полностью под вашим контролем.

**3. Порты.** Наружу только 443 (HTTPS) и 80 (выпуск сертификата Let's Encrypt). Внутри Docker-сети: 3000 (API),
5432 (Postgres), 9000 (хранилище) — наружу не публикуются. Исходящий HTTPS нужен к `api.elevenlabs.io`,
`api.anthropic.com`, `appleid.apple.com`, `oauth2.googleapis.com`, почтовому сервису и `ghcr.io` (обновления).

**4. База данных.** PostgreSQL 17 — поднимается тем же compose, отдельная установка не нужна. Миграции
применяются автоматически при старте.

**5. Ресурсы.** Минимум 2 vCPU / 4 ГБ RAM / 50 ГБ SSD, рекомендуем 4 vCPU / 8 ГБ / 100 ГБ. Под текущую нагрузку
холдинга (десятки встреч в день) этого с запасом; тяжёлые вычисления — на стороне облачных AI-сервисов.

## По данным и API

**6. Внешние API.** Два: **ElevenLabs Scribe v2** (речь → текст с разделением говорящих) и **Anthropic Claude**
(отчёт и подсказки по спикерам). Плюс сервис отправки писем с кодом входа (Resend или ваш SMTP) и проверка токенов
Apple/Google при входе. Ключи ElevenLabs и Anthropic оформляются на ADV — счета идут напрямую вам,
ориентир ≈ $0.45 за час встречи.

**7. Где данные сейчас.** Аудио удаляется с сервера сразу после расшифровки (живёт минуты). Постоянно хранятся в
базе: расшифровка, отчёт, задачи, участники, учётные записи. На телефоне копия записи хранится по настройке
пользователя (удалять сразу / 7 дней / вручную).

**8. Что переносим.** Код переносить не нужно — разворачивается готовый образ. Из данных: содержимое базы пилота
(встречи, расшифровки, отчёты, задачи, пользователи) — выгрузка `pg_dump` и восстановление в вашу базу.
Переносить аудио нечего. После проверки данные пилота на нашей стороне удаляются.

## По переносу

**9. Инструкция.** Готова: `deploy/README.md` — установка, переменные окружения, запуск, обновление, бэкапы,
таблица «что уходит наружу». Отдельно писать ничего не нужно.

**10–11. Помощь и сроки.** Разворачивает ваш администратор, я сопровождаю голосом/в переписке. По времени:
установка с нуля — 1–2 часа (включая DNS и сертификат), перенос данных пилота — ещё около часа, проверка
сквозного сценария (запись → расшифровка → отчёт → экспорт) — в тот же день.

**12. Доступы.** Мне для сопровождения ничего не нужно — при желании вы вообще не даёте мне доступ к серверу.
Вашему администратору понадобятся: SSH к серверу, DNS-запись (например `meetings.advgroup.kz`), токен к приватному
образу (выдам), ключи ElevenLabs и Anthropic (заводите вы), доступ к почтовому сервису для писем с кодом входа.

## Как сотрудники будут входить

В приложении при входе появляется выбор: **Личный** или **Корпоративный**. В корпоративном вводится код
организации — `ADV`, после чего приложение подключается к вашему серверу и весь дальнейший обмен идёт только с ним.
Вход — по коду на рабочую почту `@advgroup.kz` (или через Apple ID). Сотрудники других компаний к вашему серверу
подключиться не могут: и код организации, и список разрешённых доменов почты настраиваются на вашей стороне.

## Что остаётся у меня и почему

Справочник «код организации → адрес вашего сервера» (передаётся только код, без персональных данных), выпуск
обновлений образа и сама публикация приложения в App Store. Push-уведомления «отчёт готов» временно не работают в
корпоративном контуре: ключ Apple Push принадлежит команде разработчика и не передаётся третьим лицам — сделаем
через ретранслятор, который получает только идентификатор устройства и тип события, без содержимого встречи.

## Важное ограничение

Расшифровка и составление отчёта — облачные AI-сервисы (ElevenLabs, Anthropic): аудио и текст уходят туда на
время обработки, на их моделях эти данные не обучаются и после обработки не хранятся. Если требование — чтобы
данные вообще не покидали периметр, это другой проект: сервер с GPU и локальные модели, заметно хуже качество
казахского и разделения говорящих. Скажите, если такой вариант нужно просчитать.
