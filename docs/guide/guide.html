1Установка и вход

  1. Примите приглашение в TestFlight (письмо «You're invited to test ADV Meetings») и установите приложение.
  2. Откройте приложение, введите корпоративную почту → «Получить код».
  3. Введите 6-значный код из письма → «Войти». Вход запоминается на 90 дней.
  4. Альтернатива — «Вход с Apple» (если Apple ID привязан к корпоративной почте).
  5. При первом старте записи разрешите доступ к микрофону и уведомлениям.
Вход только с почты агентств холдинга. Письмо с кодом не пришло — проверьте «Спам» и нажмите «Получить код» ещё раз.

2Записать встречу

  1. На вкладке «Встречи» нажмите «Записать встречу» — запись начинается сразу, положите телефон ближе к говорящим.
  2. Экран можно заблокировать и убрать телефон: запись идёт в фоне, на экране блокировки — таймер и кнопки.
  3. Отметка — закладка на важном моменте, Пауза — перерыв, Стоп — завершить и отправить на обработку.
  4. «Выбрать тип встречи» (необязательно): с кем встреча → подтип → контекст → «Сохранить». Тогда отчёт составится автоматически. Тип можно указать и после расшифровки.
  5. «Отменить» → «Удалить запись» — удаляет запись безвозвратно.
Во время телефонного звонка или звонка в Meet/Zoom записать с того же iPhone нельзя — iOS не отдаёт микрофон. Для онлайн-встреч см. раздел 10.

3Что происходит после записи

  1. После «Стоп» встреча получает статус «В очереди» → «Аудио» → «Расшифровка» → «Отчёт». Приложение можно закрыть.
  2. Через несколько минут придёт push: «Отчёт готов» (тип был выбран) или «Расшифровка готова» (тип не выбран — см. разделы 4–5).
  3. Статус «Ошибка» → откройте встречу → «Повторить». Частая причина — тишина в записи.

4Проверить, кто говорил

  1. Откройте встречу со статусом «Расшифровка готова» → «Проверить спикеров и выбрать тип встречи».
  2. Для каждого говорящего проверьте имя по примеру реплики. ИИ подставляет подсказку, если уверен; иначе — кнопка «Применить».
  3. Укажите сторону: Коллега / Клиент / Вендор. Себя отметьте кнопкой «Это я».
  4. Одного человека разбило на двух — у дубля «Объединить с другим спикером». Подсказанные дубли уже объединены: проверьте, лишнее — «Отменить».
  5. «Далее: тип встречи и отчёт». Или «Сохранить спикеров без отчёта», если отчёт не нужен.

5Тип встречи и отчёт

  1. Выберите, с кем встреча: Внутренняя / С клиентом / С вендором — или из «Недавних».
  2. Выберите подтип (знакомство, бриф, статус, дебрифинг…) — он задаёт структуру отчёта по регламенту холдинга.
  3. Заполните, что знаете: проект, участники, платформа. Всё необязательно — чего нет, ИИ возьмёт из записи, а не найденное отметит «не озвучено, уточнить».
  4. Нажмите «Сформировать отчёт». Push «Отчёт готов» придёт через 1–3 минуты.

6Исправить отчёт

  1. Откройте встречу → вкладка «Отчёт»: резюме, участники, разделы по шаблону, action plan с ответственными и сроками.
  2. «Исправить с ИИ» — напишите, что не так («Спикер 2 — это Данияр», «бюджет 40 млн — это медиа», «убери пункт про наружку»), нажмите подсказки из блока «Уточнить/Ответ», затем «Пересобрать». Прежняя версия остаётся в истории («Инфо»).
  3. «Править текст» — исправьте заголовок и любой раздел вручную → «Сохранить».
  4. Другой тип отчёта по той же записи: «Исправить с ИИ» → внизу «Тип встречи» → выбрать → «Пересобрать».

7Поделиться и экспорт

  1. В карточке встречи нажмите «…» (вверху справа).
  2. «Поделиться с коллегой» → «Выбрать из аккаунтов холдинга» или ввести почту → при необходимости включите «Вместе с транскриптом» → «Поделиться». Коллега увидит встречу в своём списке.
  3. Отозвать доступ — в том же окне смахните запись в «Доступ есть у» влево.
  4. Экспорт: Word (.docx), PDF, Markdown, Транскрипт (.txt) — файл откроется в системном меню «Поделиться» (почта, Telegram, Файлы).
  5. «Удалить встречу» — удаляет расшифровку и отчёт у всех, с кем вы делились.
Встречу видят только вы и те, с кем поделились. Руководители и коллеги без доступа её не видят.

8Транскрипт и имена спикеров

  1. Вкладка «Транскрипт»: реплики по говорящим с таймкодами. Чипы сверху — фильтр по одному спикеру.
  2. Нажмите на имя спикера → «Кто это?»: выберите коллегу из аккаунтов, введите имя вручную или подпишите «Клиент N».
  3. Укажите сторону (Коллега / Клиент / Вендор) — она попадёт в отчёт. Себя — «Это я».
  4. После правки имён нажмите «Исправить с ИИ» → «Пересобрать», чтобы отчёт использовал новые имена.

9Задачи

  1. Вкладка «Задачи»: все action items со всех ваших встреч и встреч, которыми с вами поделились. Фильтры: Открытые / Все / Выполненные; группировка по срокам.
  2. Откройте задачу → «Отметить выполненной». Вернуть — «Вернуть в работу». Можно и кружком в списке или смахиванием.
  3. Ответственный и срок: измените и нажмите «Сохранить» (доступно автору встречи). Подсказки «Завтра / Через 3 дня / Неделя».
  4. Нажмите на встречу внизу карточки, чтобы открыть контекст задачи.

10Импорт файла и онлайн-встречи

  1. Импорт: «+» (вверху справа) → «Импортировать аудио / видео» → выберите файл (m4a, mp3, mp4, wav…). Дальше — как с обычной записью. Из любого приложения: «Поделиться» → ADV Meetings.
  2. Google Meet / Zoom / Teams на этом же iPhone: «+» → «Записать онлайн-встречу» → красная кнопка → в системном диалоге «Запись встречи», включите микрофон → «Начать трансляцию». После встречи вернитесь и нажмите «Остановить».
  3. Ограничение iOS: во время звонка записываются только собеседники, ваш голос — нет. Подходит для вебинаров и встреч, где вы слушаете.
  4. Чтобы записать онлайн-встречу целиком: включите запись в самом Meet/Zoom, а потом импортируйте файл (шаг 1).

  1. Выйти — «Настройки» → «Выйти». Записи и отчёты остаются на сервере и появятся после повторного входа.
